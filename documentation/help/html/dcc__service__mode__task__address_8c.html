◆ DccServiceModeTaskAddress_read()

bool DccServiceModeTaskAddress_read ( dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read CV#1 (short address) using address-only mode. Iterates address_verify 0-127 until ACK.

Algorithm:

  1. Reject if another operation is in progress (state not IDLE)
  2. Load the context: scan value 0, cleared step count, callbacks
  3. Enter READ and issue address_verify for address 0 (a refused start puts the task back to IDLE and returns false)
  4. The scan continues from DccServiceModeTaskAddress_on_primitive_complete()
* @param on_complete Called when complete: SUCCESS with the address found (0-127), or ERROR if no address was ACKed.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started, false if another operation is running.

bool DccServiceModeTaskAddress_write ( uint8_t address,

Write CV#1 (short address) then verify. Always 2 operations (write + verify).

Write CV#1 (short address) then verify. Always 2 operations (write + verify). Decoder automatically clears CV#29 bit 5 and CV#19 on success.

Algorithm:

  1. Reject addresses outside 1-127
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: address, cleared step count, callbacks
  4. Enter WRITE and issue address_write (a refused start puts the task back to IDLE and returns false)
  5. The verify runs from DccServiceModeTaskAddress_on_primitive_complete()
* @param address Address to write (1-127).
* @param on_complete Called when complete: SUCCESS or VERIFY_FAIL with the address written.
* @param on_progress Called after each step (nullable).
*
Returns
true if started, false if another operation is running or the address is out of range.

bool DccServiceModeTaskAddress_verify ( uint8_t address,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Verify CV#1 (short address) against a value (one verify op).

Algorithm:

  1. Reject addresses outside 1-127
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: address, cleared step count, callbacks
  4. Enter VERIFY and issue address_verify for the expected address (a refused start puts the task back to IDLE and returns false)
  5. The result is reported from DccServiceModeTaskAddress_on_primitive_complete()
* @param address Expected address value (1-127).
* @param on_complete Called with SUCCESS if it verified (ACK), VERIFY_FAIL otherwise.
* @param on_progress Not used by this operation (nullable).
*
Returns
true if started, false if another operation is running or the address is out of range.

◆ DccServiceModeTaskAddress_read_bit()

bool DccServiceModeTaskAddress_read_bit ( uint8_t bit_position,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read a single bit from CV#1. Reads full byte via iteration, extracts bit.

Algorithm:

  1. Reject bit positions above 6
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: bit position, scan value 0, cleared step count, callbacks
  4. Enter READ_BIT_READ and issue address_verify for address 0 (a refused start puts the task back to IDLE and returns false)
  5. The scan continues from DccServiceModeTaskAddress_on_primitive_complete(); the requested bit is extracted from the address found
* @param bit_position Bit position (0-6).
* @param on_complete Called when complete: SUCCESS with value 0 or 1, or ERROR if no address was ACKed.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started, false if another operation is running or the bit is out of range.

◆ DccServiceModeTaskAddress_write_bit()

bool DccServiceModeTaskAddress_write_bit ( uint8_t bit_position,
bool bit_value,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Write a single bit to CV#1 using read-modify-write. Reads byte first, then writes modified byte.

Algorithm:

  1. Reject bit positions above 6
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: bit position, bit value, scan value 0, cleared step count, callbacks
  4. Enter WRITE_BIT_READ and issue address_verify for address 0 to start the read scan (a refused start puts the task back to IDLE and returns false)
  5. From DccServiceModeTaskAddress_on_primitive_complete(): once the address is found, write the modified address, then verify it
* @param bit_position Bit position (0-6).
* @param bit_value Value to write.
* @param on_complete Called when complete: SUCCESS or VERIFY_FAIL with the bit written, or ERROR if the read scan found nothing.
* @param on_progress Called after each scan step of the read phase only (nullable).
*
Returns
true if started, false if another operation is running or the bit is out of range.

◆ DccServiceModeTaskAddress_on_primitive_complete()

void DccServiceModeTaskAddress_on_primitive_complete ( dcc_service_mode_result_enum result)

Notify the task module that the primitive has finished its full operation (including recovery packets).

Notify the task module that the primitive has finished its full operation (including recovery packets). Wire this into the primitive's on_complete slot via dcc_config.c. The task module advances its state machine on this event; the ACK outcome is taken from result (SUCCESS = ACK detected by the common module's pulse-width measurement, anything else = no ACK).

Algorithm:

  1. Record the ACK outcome: SUCCESS from the primitive means a valid ACK was measured, anything else means no ACK
  2. Dispatch on the current state: the three scanning states share advance_scan(), the others go to their _advance* handler
  3. Ignore the event when IDLE (no operation in progress)
* @param result Result of the primitive operation (passed through from primitive callback).
*
