◆ DccServiceModeTaskDirect_read_cv()

bool DccServiceModeTaskDirect_read_cv ( uint16_t cv_number,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read a CV byte using direct mode. Sequences 8 verify_bit operations (bits 0-7), then one verify_byte of the assembled value.

Algorithm:

  1. Reject CV numbers outside 1-1024
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, bit position 0, cleared value / any_ack / step count, callbacks
  4. Enter READ_CV and issue verify_bit for bit 0 with value 1
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The remaining steps run from DccServiceModeTaskDirect_on_primitive_complete()
* @param cv_number CV number (1-1024).
* @param on_complete Called when complete: SUCCESS with the CV byte, NO_ACK, VERIFY_FAIL, or BUSY.
* @param on_progress Called after each of the 9 steps (nullable).
*
Returns
true if started; false if another operation is running, the CV is out of range, or the first primitive could not start.

bool DccServiceModeTaskDirect_read_bit ( uint16_t cv_number,

Read a single CV bit: verify value 1, then value 0 if that was silent.

Read a single CV bit. Issues a verify_bit for value 1; if that is not ACKed, a second verify_bit for value 0 confirms the bit is really 0 rather than unanswered.

Algorithm:

  1. Reject CV numbers outside 1-1024 or bit positions above 7
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, bit position, callbacks
  4. Enter READ_BIT and issue verify_bit with value 1
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The confirming verify of value 0 runs from DccServiceModeTaskDirect_on_primitive_complete()
* @param cv_number CV number (1-1024).
* @param bit_position Bit position (0-7).
* @param on_complete Called when complete: SUCCESS with value 1 or 0, NO_ACK if neither verify was ACKed, or BUSY.
* @param on_progress Not used by this operation (nullable).
*
Returns
true if started; false if another operation is running, a parameter is out of range, or the first verify could not start.

◆ DccServiceModeTaskDirect_on_primitive_complete()

void DccServiceModeTaskDirect_on_primitive_complete ( dcc_service_mode_result_enum result)

Notify the task module that the primitive has finished its full operation (including recovery packets).

Notify the task module that the primitive has finished its full operation (including recovery packets). Wire this into the primitive's on_complete slot via dcc_config.c. The task module advances its state machine on this event; the ACK outcome is taken from result (SUCCESS = ACK detected by the common module's pulse-width measurement, anything else = no ACK).

Algorithm:

  1. Record the ACK outcome: SUCCESS from the primitive means a valid ACK was measured, anything else means no ACK
  2. Dispatch on the current state to the matching advance* step handler
  3. Ignore the event when IDLE (no operation in progress)
* @param result Result of the primitive operation (passed through from primitive callback).
*
