Detailed Description

RailCom cutout timer state machine for the command station.

Manages the one-shot Timer 2 that creates the RailCom cutout window after each DCC packet. Each state loads a one-shot duration; its action fires when that duration EXPIRES. Cumulative spec event times in parentheses (defaults shown):

  1. DELAY (26us) -> T_CS = 26us: tristate H-bridge / begin cutout
  2. SETTLING (54us) -> T_TS1 = 80us: enable UART Rx (Ch1 opens)
  3. CH1 (97us) -> T_TC1 = 177us: disable UART Rx (Ch1 closes)
  4. GAP (16us) -> T_TS2 = 193us: enable UART Rx (Ch2 opens)
  5. CH2 (261us) -> T_CE = 454us: disable UART Rx, restore H-bridge, set cutout_complete flag

This module is independent of the DCC bit encoder. Communication is through interface function pointers only (no direct includes).

Begin the cutout sequence. Called at the end bit's last edge.

Parameters
contextPointer to dcc_railcom_cutout_context_t instance.

Enters DELAY and starts the one-shot timer for the pre-cutout DELAY duration; the H-bridge is not touched until that expires (T_CS). Does nothing if no interface is wired.

Enters DELAY and starts the one-shot timer with start_delay_us; the H-bridge is tristated when it expires (T_CS). Returns without doing anything if no interface is wired.

void DccRailcomCutout_cancel ( dcc_railcom_cutout_context_t * context)
extern

Cancel the cutout sequence. Called on power-off or error.

Parameters
contextPointer to dcc_railcom_cutout_context_t instance.

Stops the one-shot timer and, if the H-bridge was already tristated, disables UART Rx and restores the H-bridge before returning to IDLE. No-op when already idle. on_cutout_complete is not fired.

Algorithm:

  1. Return if no interface is wired or the state machine is IDLE
  2. Stop the one-shot timer
  3. If the state is SETTLING, CH1, GAP or CH2 (H-bridge already tristated), disable UART Rx and restore the H-bridge
  4. Return to IDLE without firing on_cutout_complete
* @param context Pointer to dcc_railcom_cutout_context_t instance.

◆ DccRailcomCutout_timer_isr()

void DccRailcomCutout_timer_isr ( dcc_railcom_cutout_context_t * context)
extern

Timer 2 ISR entry point. Call from the one-shot timer ISR.

Parameters
contextPointer to dcc_railcom_cutout_context_t instance.

Advances the cutout state machine through DELAY -> SETTLING -> CH1 -> GAP -> CH2 -> IDLE, performing the expired phase's action and loading the next phase's duration. A call while IDLE is ignored.

Algorithm (each case is the phase whose duration just expired):

  1. DELAY (T_CS): begin_railcom_cutout(), enter SETTLING, start uart_rx_delay_us
  2. SETTLING (T_TS1): uart_rx_enable(), enter CH1, start ch1_window_us
  3. CH1 (T_TC1): uart_rx_disable(), enter GAP, start ch1_ch2_gap_us
  4. GAP (T_TS2): uart_rx_enable(), enter CH2, start ch2_window_us
  5. CH2 (T_CE): uart_rx_disable(), end_railcom_cutout(), enter IDLE, fire on_cutout_complete()
  6. IDLE or unknown: spurious interrupt, ignored

Every interface hook is optional (NULL is skipped). Returns immediately if no interface is wired.

* @param context Pointer to dcc_railcom_cutout_context_t instance.
