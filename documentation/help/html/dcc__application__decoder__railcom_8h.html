Detailed Description

Channel 2 reply builders for the decoder's RailCom callback.

Fills a dcc_railcom_response_t with the datagram id and byte layout of the common Channel 2 replies, for use inside on_railcom_request(): the application calls one builder on the callback's out response and returns DCC_RAILCOM_REPLY_DATA; the dcc_railcom_decoder engine encodes and transmits it in the cutout. Channel 1 (the address broadcast) and the ACK, NACK and BUSY code words are produced by the engine from the reply status, so they have no builders here. Stateless: nothing to initialize or wire.

Fill a POM reply (ID 0): the CV address low byte and the CV value.

Answers a POM read or write. Sets the datagram id and a two-byte payload; the engine 4/8-encodes it into Channel 2 when the callback returns DCC_RAILCOM_REPLY_DATA.

Parameters
responsePointer to the dcc_railcom_response_t to fill (the callback's out).
cv_addressCV address (1-based); the low 8 bits are sent.
valueCV value read or written.
Returns
true if filled, false if response is NULL.

Fill a POM reply (ID 0): the CV address low byte and the CV value.

Sets the datagram id, data[0] = CV address low byte, data[1] = value, count = 2.

* @param response Response to fill.
* @param cv_address CV address; the low 8 bits are sent.
* @param value CV value.
*
Returns
true if filled, false if response is NULL.

Fill an arbitrary reply: escape hatch for XPOM and other datagram ids.

Copies the bytes as given; the id is masked to its low 4 bits. A zero count produces an id-only datagram. On any argument failure the response is left untouched.

Parameters
responsePointer to the dcc_railcom_response_t to fill.
datagram_id4-bit datagram id (DCC_RAILCOM_ID_*).
dataData bytes to copy; may be NULL when count is 0.
countNumber of data bytes, at most DCC_RAILCOM_DATAGRAM_MAX_BYTES.
Returns
true if filled, false if response is NULL, data is NULL with a non-zero count, or count exceeds the maximum (response is left untouched).

Fill an arbitrary reply: escape hatch for XPOM and other datagram ids.

Validates the arguments first so a rejected call leaves the response untouched, then stores the id masked to 4 bits, the count, and copies the bytes.

* @param response Response to fill.
* @param datagram_id 4-bit datagram id.
* @param data Data bytes to copy; may be NULL when count is 0.
* @param count Number of data bytes.
*
Returns
true if filled; false (response untouched) if response is NULL, data is NULL with a non-zero count, or count exceeds DCC_RAILCOM_DATAGRAM_MAX_BYTES.
