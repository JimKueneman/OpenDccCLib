◆ DccApplicationCommandStationServiceTrack_power_on()

void DccApplicationCommandStationServiceTrack_power_on ( void )

Enable service track power output and start DCC signal generation.

Algorithm:

  1. Return if the module has not been initialized
  2. Apply track power (track_power_set(true)) first
  3. Start the timer at DCC_ONE_BIT_HALF_PERIOD_US
  4. Start the bit encoder

◆ DccApplicationCommandStationServiceTrack_power_off()

void DccApplicationCommandStationServiceTrack_power_off ( void )

Disable service track power output and stop DCC signal generation.

Algorithm:

  1. Return if the module has not been initialized
  2. Stop the bit encoder
  3. Stop the timer
  4. Remove track power (track_power_set(false)) last

◆ DccApplicationCommandStationServiceTrack_enter_service_mode()

bool DccApplicationCommandStationServiceTrack_enter_service_mode ( void )

Enter service mode on the service track.

Algorithm:

  1. Return false if the module has not been initialized
  2. Apply track power (track_power_set(true)) first
  3. Start the timer at DCC_ONE_BIT_HALF_PERIOD_US and start the bit encoder
  4. Enter the service-mode core and return its verdict
Returns
true if service mode was activated; false if the module is uninitialized or the core refused entry.

◆ DccApplicationCommandStationServiceTrack_exit_service_mode()

void DccApplicationCommandStationServiceTrack_exit_service_mode ( void )

Exit service mode, stop the signal and remove track power.

Algorithm:

  1. Return if the module has not been initialized
  2. Leave the service-mode core
  3. Stop the bit encoder, then the timer
  4. Remove track power (track_power_set(false)) last

* @param bit_position Bit position within CV#1 (0-6; bit 7 of a short address is always 0).
* @param bit_value Bit value to write (true = 1, false = 0).
* @param on_complete Completion callback; value = the bit value verified (0 or 1).
* @param on_progress Progress callback, called after each step; may be NULL.
*
Returns
true if the task was started; false if the module is uninitialized, the task hook is not wired, the task layer is busy, or bit_position is out of range.
