Detailed Description

CV read/write abstraction with decoder lock and factory reset.

Wraps the user-provided CV read/write callbacks with the decoder lock (CV 15 must equal CV 16 for a write to succeed), factory-reset detection (a write of 8 to CV 8 triggers the reset hook instead of storing a value), CV 29 filtering (reserved bit 6 forced clear, unsupported feature bits removed by the application hook) and the CV 257-512 indexed window (routed through the CV 31/32 page pointer to the indexed hooks).

bool DccCvStorage_read ( uint16_t cv_number,
uint8_t * value )
extern

Read a CV value.

CV 1-256 go straight to the cv_read hook. CV 257-512 (the indexed window) are resolved through the CV 31/32 page pointer and read with the cv_read_indexed hook.

Parameters
cv_numberCV number (1-based).
valuePointer to receive the value.
Returns
true if the read succeeded; false when the required hook is absent, the page pointer could not be read, or the hook itself failed.

Algorithm:

  1. Return false if the cv_read hook is absent.
  2. CV 257-512 (indexed window): return false without cv_read_indexed or a readable CV 31/32 page pointer; otherwise read offset cv_number - 257 of that page through cv_read_indexed.
  3. Any other CV: read through cv_read.
* @param cv_number CV number (1-based).
* @param value     Pointer to receive the value.
*
Returns
true if the read succeeded; false when a hook is absent, the page pointer could not be read, or the hook failed.

◆ DccCvStorage_write()

bool DccCvStorage_write ( uint16_t cv_number,
uint8_t value )
extern

Write a CV value with decoder lock enforcement.

CV 15 and CV 16 are always written (they control the lock). A write of the value 8 to CV 8 (the read-only Manufacturer ID) is a factory-reset trigger: the factory_reset hook is called if provided, nothing is stored, and the lock is bypassed; any other CV 8 value is forwarded like an ordinary CV. Every other write is refused while the lock is engaged (CV 15 != CV 16). CV 257-512 are routed through the CV 31/32 page pointer to the cv_write_indexed hook. A CV 29 write has reserved bit 6 forced clear and is passed through cv29_apply_supported_features before the re-encoded value is stored.

Parameters
cv_numberCV number (1-based).
valueValue to write.
Returns
true if the write succeeded (or the reset was triggered); false when locked, the required hook is absent, the page pointer could not be read, or the hook failed.

Algorithm:

  1. Return false if the cv_write hook is absent.
  2. CV 15 / CV 16: always forward to cv_write (they control the lock).
  3. CV 8 with value 8: call factory_reset if provided, store nothing, return true (bypasses the lock). Any other CV 8 value falls through as an ordinary CV.
  4. Return false if the lock is engaged (CV 15 != CV 16).
  5. CV 257-512 (indexed window): return false without cv_write_indexed or a readable CV 31/32 page pointer; otherwise write through cv_write_indexed.
  6. CV 29: force reserved bit 6 clear, decode to flags, let the application clear unsupported features via cv29_apply_supported_features (if provided), re-encode and forward to cv_write.
  7. Any other CV: forward to cv_write.
* @param cv_number CV number (1-based).
* @param value     Value to write.
*
Returns
true if the write succeeded or the reset was triggered; false when locked, a hook is absent, the page pointer could not be read, or the hook failed.

bool DccCvStorage_is_locked ( void )
extern

Check if the decoder lock is engaged.

Reads CV 15 and CV 16 through the cv_read hook on every call.

Returns
true if locked (CV 15 != CV 16); false if unlocked, or if either CV could not be read.

Algorithm:

  1. Report unlocked if the cv_read hook is absent.
  2. Read CV 15 and CV 16; a failed read also reports unlocked.
  3. Locked when the two values differ.
Returns
true if locked (CV 15 != CV 16); false if unlocked or unreadable.
