◆ DccApplicationMainTrack_power_on()

void DccApplicationMainTrack_power_on ( void )

Enable main track power output and start DCC signal generation.

Algorithm:

  1. Return if not initialized.
  2. track_power_set(true).
  3. timer_start(DCC_ONE_BIT_HALF_PERIOD_US).
  4. encoder_start().

◆ DccApplicationMainTrack_power_off()

void DccApplicationMainTrack_power_off ( void )

Disable main track power output and stop DCC signal generation.

Algorithm:

  1. Return if not initialized.
  2. encoder_stop().
  3. timer_stop().
  4. track_power_set(false).

dcc_address_t address,
dcc_tag_enum tag,
dcc_priority_enum priority,
bool auto_refresh )

Insert a packet into the main track scheduler.

Returns false when uninitialized, otherwise forwards every argument to the scheduler_insert hook.

* @param packet       The packet to schedule.
* @param address      Address used as the duplicate-combining key.
* @param tag          Sub-key for duplicate combining.
* @param priority     Packet priority level.
* @param auto_refresh true = keep in refresh cycle indefinitely.
*
Returns
true if the packet was scheduled; false if no free slot or the module is not initialized.
