bool DccServiceModeTaskRegister_read_cv ( uint16_t cv_number,
dcc_decoder_type_enum decoder_type,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read a CV byte using register mode. Iterates register_verify 0-255 until ACK.

Algorithm:

  1. Map the CV to a register for decoder_type; reject if the CV is not register-accessible
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: register, decoder type, scan value 0, cleared step count, callbacks
  4. Enter READ_CV and issue register_verify for value 0
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The scan continues from DccServiceModeTaskRegister_on_primitive_complete()
* @param cv_number CV number to read (mapped to register via decoder_type).
* @param decoder_type Mobile or Accessory - determines CV-to-register mapping.
* @param on_complete Called when complete: SUCCESS with the CV byte found, ERROR if no value was ACKed, or BUSY.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started; false if another operation is running, the CV is not accessible in register mode, or the first verify could not start.

Read a single CV bit using register mode. Reads full byte, extracts bit.

Algorithm:

  1. Reject bit positions above 7
  2. Map the CV to a register for decoder_type; reject if the CV is not register-accessible
  3. Reject if another operation is in progress (state not IDLE)
  4. Load the context: register, decoder type, bit position, scan value 0, cleared step count, callbacks
  5. Enter READ_BIT_READ_BYTE and issue register_verify for value 0
  6. If the primitive refuses to start, return to IDLE and report failure to the caller
  7. The scan continues from DccServiceModeTaskRegister_on_primitive_complete(); the requested bit is extracted from the value found
* @param cv_number CV number (mapped to register via decoder_type).
* @param bit_position Bit position (0-7).
* @param decoder_type Mobile or Accessory - determines CV-to-register mapping.
* @param on_complete Called when complete: SUCCESS with value 0 or 1, ERROR if no byte value was ACKed, or BUSY.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started; false if another operation is running, the bit is above 7, the CV is not register-accessible, or the first verify could not start.

Write a single CV bit using register mode. Read-modify-write sequence.

Algorithm:

  1. Reject bit positions above 7
  2. Map the CV to a register for decoder_type; reject if the CV is not register-accessible
  3. Reject if another operation is in progress (state not IDLE)
  4. Load the context: register, decoder type, bit position, bit value, scan value 0, cleared step count, callbacks
  5. Enter WRITE_BIT_READ_BYTE and issue register_verify for value 0 to start the read scan
  6. If the primitive refuses to start, return to IDLE and report failure to the caller
  7. From DccServiceModeTaskRegister_on_primitive_complete(): once the byte is found, write the modified byte, then verify it
* @param cv_number CV number (mapped to register via decoder_type).
* @param bit_position Bit position (0-7).
* @param bit_value Value to write.
* @param decoder_type Mobile or Accessory - determines CV-to-register mapping.
* @param on_complete Called when complete: SUCCESS or VERIFY_FAIL with the bit written, ERROR if the read scan found nothing, or BUSY.
* @param on_progress Called after each scan step of the read phase only (nullable).
*
Returns
true if started; false if another operation is running, the bit is above 7, the CV is not register-accessible, or the first verify could not start.

Verify a single register value (one register-verify op).

Algorithm:

  1. Map the CV to a register for decoder_type; reject if the CV is not register-accessible
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: register, value, decoder type, cleared step count, callbacks
  4. Enter VERIFY_VALUE and issue register_verify for the expected value
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The result is reported from DccServiceModeTaskRegister_on_primitive_complete()
* @param cv_number CV number (mapped to a physical register for decoder_type).
* @param value Expected byte value.
* @param decoder_type Mobile or Accessory (selects the CV->register map).
* @param on_complete Called with SUCCESS if the value verified (ACK), VERIFY_FAIL otherwise.
* @param on_progress Not used by this operation (nullable).
*
Returns
true if started; false if another operation is running, the CV is not register-accessible, or the verify could not start.

◆ DccServiceModeTaskRegister_factory_reset()

bool DccServiceModeTaskRegister_factory_reset ( dcc_service_mode_task_on_complete_callback_t on_complete)

Issue a factory reset (write 8 to register 8). Applies to both Mobile and Accessory.

Algorithm:

  1. Reject if another operation is in progress (state not IDLE)
  2. Load the context: cleared step count, completion callback, no progress callback
  3. Enter FACTORY_RESET and issue register_write(8, 8)
  4. If the primitive refuses to start, return to IDLE and report failure to the caller
  5. The result (SUCCESS on ACK, otherwise NO_ACK) is reported from DccServiceModeTaskRegister_on_primitive_complete()
* @param on_complete Called when the write completes: SUCCESS if ACKed, NO_ACK otherwise; value 0.
*
Returns
true if started; false if another operation is running or the write could not start.

◆ DccServiceModeTaskRegister_on_primitive_complete()

void DccServiceModeTaskRegister_on_primitive_complete ( dcc_service_mode_result_enum result)

Notify the task module that the primitive has finished its full operation (including recovery packets).

Notify the task module that the primitive has finished its full operation (including recovery packets). Wire this into the primitive's on_complete slot via dcc_config.c. The task module advances its state machine on this event; the ACK outcome is taken from result (SUCCESS = ACK detected by the common module's pulse-width measurement, anything else = no ACK).

Algorithm:

  1. Record the ACK outcome: SUCCESS from the primitive means a valid ACK was measured, anything else means no ACK
  2. Dispatch on the current state: the three scanning states share advance_scan(), the others go to their _advance* handler
  3. Ignore the event when IDLE (no operation in progress)
* @param result Result of the primitive operation (passed through from primitive callback).
*
