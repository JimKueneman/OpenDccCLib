Detailed Description

Direct mode CV programming (byte write/verify, bit write/verify).

bool DccServiceModeDirect_write_byte ( dcc_service_mode_direct_context_t * context,
uint16_t cv_number,
uint8_t value )
extern

Write a byte to a CV using direct mode.

Single-step write with a recovery phase; the result is delivered through the interface on_complete callback.

Parameters
contextPointer to dcc_service_mode_direct_context_t instance.
cv_numberCV number to write (1-1024).
valueByte value to write.
Returns
true if the operation started, false if cv_number is out of range or the common module is busy.

Algorithm:

  1. Return false if cv_number is outside 1-1024 or the common module is busy
  2. Encode the 0-based wire CV (cv_number - 1): data[0] = DCC_SERVICE_DIRECT_WRITE_PREFIX | CV bits 9-8, data[1] = CV bits 7-0, data[2] = value, then the XOR byte
  3. Latch this context for the callback and start a write operation with DCC_SERVICE_MODE_COMMAND_REPEAT command packets and DCC_SERVICE_MODE_RECOVERY_COUNT recovery packets
* @param context Pointer to dcc_service_mode_direct_context_t instance.
* @param cv_number CV number to write (1-1024).
* @param value Byte value to write.
*
Returns
true if the operation started, false if cv_number is out of range or the common module is busy.

Write a single bit to a CV using direct mode.

Single-step bit-manipulation write with a recovery phase. Result via on_complete.

Parameters
contextPointer to dcc_service_mode_direct_context_t instance.
cv_numberCV number to write (1-1024).
bit_positionBit position within the CV (0-7).
bit_valueValue to write (true = 1, false = 0).
Returns
true if the operation started, false if cv_number or bit_position is out of range or the common module is busy.

Algorithm:

  1. Return false if cv_number is outside 1-1024, bit_position is above 7, or the common module is busy
  2. Encode the 0-based wire CV (cv_number - 1): data[0] = DCC_SERVICE_DIRECT_BIT_PREFIX | CV bits 9-8, data[1] = CV bits 7-0, data[2] = 1111DBBB (D = bit_value, BBB = bit_position), then the XOR byte
  3. Latch this context for the callback and start a write operation with DCC_SERVICE_MODE_COMMAND_REPEAT command packets and DCC_SERVICE_MODE_RECOVERY_COUNT recovery packets
* @param context Pointer to dcc_service_mode_direct_context_t instance.
* @param cv_number CV number to write (1-1024).
* @param bit_position Bit position within the CV (0-7).
* @param bit_value Value to write (true = 1, false = 0).
*
Returns
true if the operation started, false if cv_number or bit_position is out of range or the common module is busy.
