Detailed Description

Per-channel DCC output hardware drivers.

Each DCC output channel (main track, service track) has its own output pin and H-bridge enable. Both channels are clocked by the shared 58 us timer (shared_timer_start/shared_timer_stop in dcc_config_t); there is no per-channel timer.
