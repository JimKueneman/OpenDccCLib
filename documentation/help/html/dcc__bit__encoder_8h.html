Detailed Description

ISR-level bit encoder for DCC packet transmission.

Serializes a dcc_packet_t into preamble + framed bytes + end bit on the wire from a fixed-period 58 us tick ISR. The encoder decides on each tick whether the next tick must toggle the DCC output pin (toggle_next); the caller performs that toggle through pin_toggle() before calling DccBitEncoder_tick_isr() again. A one-bit half is one tick (58 us), a zero-bit half is two ticks (116 us).

The bit encoder holds a single active packet plus a packet_loaded flag: it transmits the active packet, and on completion signals the main loop, which loads the next packet via DccBitEncoder_load_packet(). (There is no separate front/back buffer swap; the reload happens within the inter-packet window.)

void DccBitEncoder_tick_isr ( dcc_bit_encoder_context_t * context)
extern

Fixed-period tick ISR entry point — call every 58us from shared timer.

Parameters
contextPointer to dcc_bit_encoder_context_t instance.

The timer period never changes. One-bits toggle every tick (58us half-period), zero-bits skip one tick and toggle on the second (116us half-period). The caller must toggle the pin via pin_toggle() BEFORE this call whenever toggle_next is set; this call then advances the state machine and recomputes toggle_next for the next tick. The RailCom cutout (railcom_cutout_begin) is armed on the tick whose toggle is the end bit's last edge, and on_packet_complete fires when the end bit is done.

Algorithm:

  1. If no interface or not running, clear toggle_next and return
  2. If a cutout arm is pending, clear it and call railcom_cutout_begin(): the toggle the caller just performed was the end bit's last edge, so T_CS is measured from that edge (S-9.3.2 Table 1)
  3. Count the tick; a one-bit half is 1 tick, a zero-bit half is 2. If the half-bit is not over yet, clear toggle_next and return
  4. Half-bit over: reset the tick counter. If this was the first half, set toggle_next and return
  5. Full bit over: advance the state machine
    • IDLE: if packet_loaded (read after a DCC_COMPILER_BARRIER()), load preamble_count and go to PREAMBLE; either way the next bit is a one
    • PREAMBLE: count down; at 0 go to START_BIT (a zero) with byte_index 0
    • START_BIT: go to DATA at bit 7 of the current byte
    • DATA / END_BIT: see _tick_handle_data() / _tick_handle_end_bit()
  6. Set toggle_next: every new bit starts with a first-half toggle
* @param context Pointer to dcc_bit_encoder_context_t instance.

void DccBitEncoder_load_packet ( dcc_bit_encoder_context_t * context,
const dcc_packet_t * packet )
extern

Load a new packet for transmission.

Parameters
contextPointer to dcc_bit_encoder_context_t instance.
packetPointer to dcc_packet_t to transmit. Contents are copied.

Called from main loop context, only while DccBitEncoder_is_idle() is true. The copy is published to the ISR as a whole; the encoder begins transmitting the packet, starting with its preamble, at the next full-bit boundary.

Copies the data bytes (capped at DCC_PACKET_MAX_BYTES), byte_count, preamble_bits and repeat_count into active_packet, then sets packet_loaded behind a DCC_COMPILER_BARRIER() so the ISR can never see the flag before every byte is stored. The IDLE state of the tick ISR picks the packet up at the next full-bit boundary.

* @param context Pointer to dcc_bit_encoder_context_t instance.
* @param packet Pointer to dcc_packet_t to transmit. Contents are copied.
*
Warning
Call only while DccBitEncoder_is_idle() is true; there is no back buffer.

Start the bit encoder. Begins generating DCC signal (idle one-bits until a packet is loaded).

Sets running, resets to IDLE at the first half of a bit and requests a toggle on the next tick, so the line clocks idle one-bits until a packet is loaded. Any pending cutout arm is dropped.
