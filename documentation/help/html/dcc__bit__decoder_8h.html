Receives edge timestamps from the input-capture ISR, classifies half-bit periods as one or zero using timing thresholds from S-9.1, pairs half-bits into complete bits, detects preamble sequences, and assembles raw packet bytes. Complete packets are forwarded via callback.

Initialize the bit decoder module.

Stores the interface and resets the edge pairing and packet assembler, so the next edge is taken as the timing baseline and a fresh preamble search begins.

Parameters

Stores the interface, marks the next edge as the timing baseline, clears the half-bit pairing and resets the assembler to a preamble search.

◆ DccBitDecoder_edge()

void DccBitDecoder_edge ( uint32_t timestamp_usec)
extern

Process a signal edge from the input-capture ISR.

Call this from the input-capture ISR on every edge (rising or falling). Each half-period is classified as one or zero against the S-9.1 thresholds and paired with its neighbour to form a bit; a half-period longer than the maximum restarts the preamble search. Complete packets are delivered through on_packet_received at the end bit.

Parameters
timestamp_usecMicrosecond timestamp of the edge from a free-running counter; wraparound between edges is tolerated.

Algorithm:

  1. First edge after initialize (or after a RailCom end bit): record it as the baseline and return; it yields no half-period.
  2. Compute the time elapsed since the previous edge (unsigned subtraction, so counter wraparound is tolerated) and record this edge as the new baseline.
  3. Elapsed at or above DCC_DECODER_HALF_BIT_MAX_US: invalid; drop any pending half and restart the preamble search.
  4. Classify the half-period: under DCC_DECODER_HALF_BIT_THRESHOLD_US is SHORT (one-bit), otherwise LONG (zero-bit).
  5. Pair with the pending half: none pending stores this one; a matching pair emits a bit through _on_bit and clears the pending half; a mismatch does NOT restart the preamble search – this half simply becomes the first half of a new pair.
* @param timestamp_usec Microsecond timestamp of the edge.
