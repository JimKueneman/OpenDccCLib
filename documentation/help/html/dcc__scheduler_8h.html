Detailed Description

Packet scheduler with duplicate combining and auto-refresh.

Manages a static array of scheduler slots. Supports:

  • Duplicate combining via (address, tag) composite key
  • Auto-refresh of speed/function slots per NMRA requirements
  • One-shot packets always go out before refresh slots; priority (e-stop > speed > function > accessory > CV > idle) ranks only the one-shots
  • Round-robin through refresh slots, with a prompt burst after every insert

◆ DccScheduler_run()

void DccScheduler_run ( dcc_scheduler_context_t * context)
extern

Main loop processing. Selects next packet and feeds to bit encoder.

Parameters
contextPointer to dcc_scheduler_context_t instance.

Called from DccConfig_run(). Does nothing until the bit encoder has finished the previous packet and reports idle. Then sends the highest-priority pending one-shot if there is one, otherwise the next auto-refresh slot in round-robin order, otherwise an idle packet. Two consecutive packets to the same short address 112-127 are separated by an idle packet (S-9.2 Section C footnote 11).

Algorithm:

  1. Return if no interface is wired
  2. After the first packet, return until packet_complete_flag is set, then clear it
  3. Return if the bit encoder does not report idle (belt and suspenders)
  4. Age every refresh slot by one packet cycle
  5. Pick the highest-priority one-shot; if found:
    • If its first byte is 0x70-0x7F and equals last_addr_byte, load an idle spacer instead (S-9.2 Section C footnote 11 5 ms gap) and retry next cycle
    • Otherwise load it, record last_addr_byte, fire on_packet_sent, decrement repeat_count and free the slot when it reaches 0
  6. Else pick the next refresh slot; if found, apply the same same-address guard, load it, fire on_packet_sent, spend one burst send and zero unsent_cycles
  7. Else load an idle packet
* @param context Pointer to dcc_scheduler_context_t instance.

Insert or update a packet in the scheduler.

Parameters
contextPointer to dcc_scheduler_context_t instance.

If a slot with matching (address, tag) exists and is active, its packet data is overwritten (duplicate combining). Otherwise a new slot is allocated. Every insert re-arms the refresh slot's prompt burst (refresh_prompt_sends full-rate sends before it drops to the keep-alive).

Parameters
packetPointer to dcc_packet_t to schedule.
Note
Contents of the packet are copied; the caller's copy may be reused after the call.
Parameters
addressDCC address for duplicate combining key.
tagSub-key for duplicate combining (dcc_tag_enum).
priorityPacket priority level (dcc_priority_enum).
auto_refreshtrue = keep in refresh cycle indefinitely.
Returns
true if packet was scheduled, false if no free slots or if a one-shot was handed over with repeat_count 0 (it would never be sent).

Algorithm:

  1. Refuse a one-shot whose repeat_count is 0 (it would never be sent and never freed)
  2. Look for an active slot with the same (address, tag)
  3. If none, take a free slot (fail if there is none) and zero its unsent_cycles
  4. If one exists, it is an auto-refresh slot and the cold tier is off, move refresh_index to it so the changed command takes the next refresh turn
  5. Copy the packet bytes, byte_count, preamble_bits and repeat_count into the slot
  6. Store address, tag, priority and auto_refresh, and mark the slot active
  7. Re-arm the prompt burst (prompt_sends_left = refresh_prompt_sends); unsent_cycles is left alone because an insert is not a send
* @param context Pointer to dcc_scheduler_context_t instance.
* @param packet Pointer to dcc_packet_t to schedule (contents are copied).
* @param address DCC address for duplicate combining key.
* @param tag Sub-key for duplicate combining.
* @param priority Packet priority level (ranks one-shots only).
* @param auto_refresh true = keep in refresh cycle indefinitely.
*
Returns
true if the packet was scheduled, false if no free slot or if a one-shot was handed over with repeat_count 0.
