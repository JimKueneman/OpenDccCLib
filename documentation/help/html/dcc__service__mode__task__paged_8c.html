◆ DccServiceModeTaskPaged_read_cv()

bool DccServiceModeTaskPaged_read_cv ( uint16_t cv_number,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read a CV byte using paged mode. Iterates paged_verify 0-255 until ACK.

Algorithm:

  1. Reject CV numbers outside 1-1024
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, scan value 0, cleared step count, callbacks
  4. Enter READ_CV and issue paged_verify for value 0
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The scan continues from DccServiceModeTaskPaged_on_primitive_complete()
* @param cv_number CV number (1-1024).
* @param on_complete Called when complete: SUCCESS with the CV byte found, ERROR if no value was ACKed, or BUSY.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started; false if another operation is running, the CV is out of range, or the first verify could not start.

Write a CV byte then verify. Always 2 operations (write + targeted verify).

Algorithm:

  1. Reject CV numbers outside 1-1024
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, value, cleared step count, callbacks
  4. Enter WRITE_CV and issue paged_write
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The verify runs from DccServiceModeTaskPaged_on_primitive_complete()
* @param cv_number CV number (1-1024).
* @param value Byte to write.
* @param on_complete Called when complete: SUCCESS or VERIFY_FAIL with the byte written, or BUSY.
* @param on_progress Called after each step (nullable).
*
Returns
true if started; false if another operation is running, the CV is out of range, or the write could not start.

bool DccServiceModeTaskPaged_read_bit ( uint16_t cv_number,
uint8_t bit_position,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Read a single CV bit using paged mode. Reads full byte, extracts bit.

Algorithm:

  1. Reject CV numbers outside 1-1024 or bit positions above 7
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, bit position, scan value 0, cleared step count, callbacks
  4. Enter READ_BIT_READ_BYTE and issue paged_verify for value 0
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. The scan continues from DccServiceModeTaskPaged_on_primitive_complete(); the requested bit is extracted from the value found
* @param cv_number CV number (1-1024).
* @param bit_position Bit position (0-7).
* @param on_complete Called when complete: SUCCESS with value 0 or 1, ERROR if no byte value was ACKed, or BUSY.
* @param on_progress Called after each scan step (nullable).
*
Returns
true if started; false if another operation is running, a parameter is out of range, or the first verify could not start.

◆ DccServiceModeTaskPaged_write_bit()

bool DccServiceModeTaskPaged_write_bit ( uint16_t cv_number,
uint8_t bit_position,
bool bit_value,
dcc_service_mode_task_on_complete_callback_t on_complete,
dcc_service_mode_task_on_progress_callback_t on_progress )

Write a single CV bit using paged mode. Read-modify-write sequence.

Algorithm:

  1. Reject CV numbers outside 1-1024 or bit positions above 7
  2. Reject if another operation is in progress (state not IDLE)
  3. Load the context: CV number, bit position, bit value, scan value 0, cleared step count, callbacks
  4. Enter WRITE_BIT_READ_BYTE and issue paged_verify for value 0 to start the read scan
  5. If the primitive refuses to start, return to IDLE and report failure to the caller
  6. From DccServiceModeTaskPaged_on_primitive_complete(): once the byte is found, write the modified byte, then verify it
* @param cv_number CV number (1-1024).
* @param bit_position Bit position (0-7).
* @param bit_value Value to write.
* @param on_complete Called when complete: SUCCESS or VERIFY_FAIL with the bit written, ERROR if the read scan found nothing, or BUSY.
* @param on_progress Called after each scan step of the read phase only (nullable).
*
Returns
true if started; false if another operation is running, a parameter is out of range, or the first verify could not start.

◆ DccServiceModeTaskPaged_on_primitive_complete()

void DccServiceModeTaskPaged_on_primitive_complete ( dcc_service_mode_result_enum result)

Notify the task module that the primitive has finished its full operation (including recovery packets).

Notify the task module that the primitive has finished its full operation (including recovery packets). Wire this into the primitive's on_complete slot via dcc_config.c. The task module advances its state machine on this event; the ACK outcome is taken from result (SUCCESS = ACK detected by the common module's pulse-width measurement, anything else = no ACK).

Algorithm:

  1. Record the ACK outcome: SUCCESS from the primitive means a valid ACK was measured, anything else means no ACK
  2. Dispatch on the current state: the three scanning states share advance_scan(), the others go to their _advance* handler
  3. Ignore the event when IDLE (no operation in progress)
* @param result Result of the primitive operation (passed through from primitive callback).
*
