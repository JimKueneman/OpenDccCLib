uint8_t DccRailcomUtilities_encode_ch2 ( const dcc_railcom_response_t * response,
uint8_t * out )

Encode a Channel 2 datagram (ID + up to 6 data bytes) into codewords.

Algorithm:

  1. Return 0 if the response holds no data bytes
  2. Encode (datagram_id << 8) | data[0] as two 6-bit codewords, as for Channel 1
  3. Encode each further data byte's low 6 bits as one codeword
  4. Return the number of codewords written (count + 1)
* @param response Pointer to the dcc_railcom_response_t datagram to encode.
* @param out Output buffer receiving the encoded bytes (size DCC_RAILCOM_DATAGRAM_MAX_BYTES + 1).
*
Returns
Number of encoded bytes written, or 0 if the datagram is empty.

◆ DccRailcomUtilities_decode_ch1()

bool DccRailcomUtilities_decode_ch1 ( uint8_t byte0,
uint8_t byte1,
dcc_railcom_datagram_t * out )

Decode RailCom Channel 1 (2 codewords) into a 12-bit datagram.

Clears the output first. Both codewords must decode to data values (below 0x40); ACK, NACK and invalid words fail the decode. The 12-bit result is split into datagram_id (upper 4 bits) and data[0], with count 1 and valid set.

* @param byte0 First received codeword.
* @param byte1 Second received codeword.
* @param out Out: decoded dcc_railcom_datagram_t (valid only when true).
*
Returns
true if both codewords decoded; false on an invalid codeword.

◆ DccRailcomUtilities_decode_ch2()

bool DccRailcomUtilities_decode_ch2 ( const uint8_t * raw_bytes,
uint8_t raw_count,
dcc_railcom_datagram_t * out )

Decode RailCom Channel 2 (up to 6 codewords) into a datagram.

Algorithm:

  1. Clear the output
  2. Decode codewords in order, at most DCC_RAILCOM_CH2_MAX_BYTES, stopping at the first ACK / NACK / invalid word (S-9.3.2 allows ACK filler after a short datagram, so what came before is kept)
  3. Fail if fewer than two data words were decoded
  4. Split the first two 6-bit values into datagram_id and data[0]
  5. Append each further value as one data byte, up to DCC_RAILCOM_DATAGRAM_MAX_BYTES
  6. Set valid and return true
* @param raw_bytes Received Channel 2 codewords (after the 2 Channel 1 bytes).
* @param raw_count Number of Channel 2 codewords available.
* @param out Out: decoded dcc_railcom_datagram_t (valid only when true).
*
Returns
true if at least two codewords decoded validly; false otherwise.
