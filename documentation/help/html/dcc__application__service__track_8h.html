Detailed Description

Application-layer API for service track (programming) operations.

Legacy application layer for the service track (programming) output: power control, service mode entry/exit, and the direct, paged, register and address-only programming operations, forwarded through an interface struct that the application (or test) populates. This module is still compiled and unit-tested but is NOT wired by dcc_config.c; the current command-station API is dcc_application_command_station_service_track. Every call is a no-op (or returns false) until DccApplicationServiceTrack_initialize has been called.

◆ DccApplicationServiceTrack_power_on()

void DccApplicationServiceTrack_power_on ( void )
extern

Enable service track power output and start DCC signal generation.

Calls track_power_set(true), timer_start with the one-bit half period (DCC_ONE_BIT_HALF_PERIOD_US) and encoder_start, in that order. No-op before initialization.

Algorithm:

  1. Return if not initialized.
  2. track_power_set(true).
  3. timer_start(DCC_ONE_BIT_HALF_PERIOD_US).
  4. encoder_start().

◆ DccApplicationServiceTrack_power_off()

void DccApplicationServiceTrack_power_off ( void )
extern

Disable service track power output and stop DCC signal generation.

Calls encoder_stop, timer_stop and track_power_set(false), in that order (the reverse of power-on). No-op before initialization.

Algorithm:

  1. Return if not initialized.
  2. encoder_stop().
  3. timer_stop().
  4. track_power_set(false).

◆ DccApplicationServiceTrack_enter()

bool DccApplicationServiceTrack_enter ( void )
extern

Enter service mode on the service track.

Powers the track (track_power_set, timer_start, encoder_start) and then calls the enter_service_mode hook. The track stays powered even when the hook refuses.

Returns
true if service mode was activated; false if the hook refused (busy) or the module is not initialized.

Algorithm:

  1. Return false if not initialized.
  2. Power the track: track_power_set(true), timer_start(DCC_ONE_BIT_HALF_PERIOD_US), encoder_start().
  3. Return the result of the enter_service_mode hook; the track stays powered even when the hook refuses.
Returns
true if service mode was activated; false if the hook refused or the module is not initialized.

◆ DccApplicationServiceTrack_exit()

void DccApplicationServiceTrack_exit ( void )
extern

Exit service mode on the service track.

Calls the exit_service_mode hook, then stops the encoder and timer and removes track power. No-op before initialization.

Algorithm:

  1. Return if not initialized.
  2. exit_service_mode().
  3. encoder_stop(), timer_stop(), track_power_set(false).
