◆ DccPacketDecoder_process_packet()

void DccPacketDecoder_process_packet ( const uint8_t * data,
uint8_t byte_count )

Process a complete raw packet from the bit decoder.

Algorithm:

  1. Drop the packet if the XOR byte does not check.
  2. Idle packet (0xFF): ignore without touching the reset counter.
  3. Broadcast reset (00 00): count it; DCC_SERVICE_MODE_RESET_PRE_COUNT consecutive resets arm service mode. Return.
  4. Byte 0 in 0x70-0x7F while service mode is armed: _dispatch_service_mode. Return.
  5. Any other packet clears the reset counter and disarms service mode.
  6. Accessory packet (10xxxxxx): _dispatch_accessory (only an accessory decoder answers). Return.
  7. An accessory decoder ignores every multifunction packet, including broadcast.
  8. Short address (0x00-0x7F): accept if ours or broadcast, or if it is the CV19 consist address, this is a short/long decoder and the instruction is one a consist answers (_via_consist is set for the dispatch).
  9. Long address (0xC0-0xE7, 4+ bytes): accept only when our address is long and equal.
  10. Fire on_addressed_packet, dispatch the instruction bytes (address and XOR excluded), then clear _via_consist.
* @param data Raw packet bytes (including XOR byte).
* @param byte_count Number of bytes in the packet.
*

◆ DccPacketDecoder_enqueue()

void DccPacketDecoder_enqueue ( const uint8_t * data,
uint8_t byte_count )

Enqueue a raw decoded packet for deferred dispatch (called at the end bit).

Enqueue a raw decoded packet for deferred dispatch.

Algorithm:

  1. Compute the next tail; if it meets head the FIFO is full – drop the packet (the command station resends).
  2. Copy up to DCC_PACKET_MAX_BYTES into the tail slot, then publish the new tail.
* @param data Raw packet bytes (including XOR).
* @param byte_count Number of bytes in data.
